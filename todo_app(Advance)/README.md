سیستم مدیریت وظایف (To-Do List Application)

 معرفی پروژه:
این پروژه یک اپلیکیشن وب ساده و کامل است که با استفاده از فریم‌ورک Django توسعه یافته است.
 هدف اصلی این سیستم، فراهم کردن یک محیط کاربری ساده برای کاربران جهت افزودن، مشاهده، مدیریت (ویرایش/حذف) وظایف روزانه یا پروژه‌ها می‌باشد.

این پروژه به طور خاص مهارت‌های زیر را در توسعه وب مبتنی بر Django به نمایش می‌گذارد:

CRUD Operations: پیاده‌سازی کامل عملیات ایجاد، خواندن، به‌روزرسانی و حذف داده‌ها.
Model-View-Template (MVT): پیاده‌سازی معماری استاندارد Django.
Database Interaction: تعامل کارآمد با پایگاه داده SQLite از طریق ORM.

 ویژگی‌های کلیدی:
افزودن وظایف جدید: امکان ثبت سریع وظایف جدید به لیست.
نمایش لیست جامع: نمایش تمامی وظایف در یک صفحه قابل پیمایش.
حذف آسان: قابلیت حذف وظایف غیرضروری از لیست.
ساختاردهی پروژه: پیروی از بهترین شیوه‌های ساختاردهی اپلیکیشن‌های Django.
 نصب و راه‌اندازی پروژه (Setup & Installation)

برای اجرای این پروژه، مراحل زیر را دنبال کنید:

پیش‌ نیازها:
Python 3.x
Django (نسخه 5.2.7 یا مشابه)
۱. کپی کردن کدها
مطمئن شوید که تمام فایل‌ها و ساختار پوشه‌ها مطابق با ساختار پروژه Django استاندارد تنظیم شده‌اند.

۲. نصب وابستگی‌ها (Dependencies)
در مسیر ریشه پروژه (todo_app/) دستور زیر را اجرا کنید تا همه کتابخانه‌های مورد نیاز نصب شوند:

pip install -r requirements.txt 
# اگر فایل requirements.txt ندارید، موارد زیر را دستی نصب کنید:
# pip install django

۳. تنظیمات پایگاه داده (Database Setup)
فایل settings.py به طور پیش‌فرض از SQLite استفاده می‌کند. برای اطمینان از شروع کار صحیح، دستورات اولیه Migration را اجرا کنید:

python manage.py makemigrations todo
python manage.py migrate

۴. اجرای سرور (Run Server)
پس از اتمام مراحل بالا، پروژه را با دستور زیر اجرا کنید:

python manage.py runserver
سپس مرورگر خود را باز کرده و به آدرس رو به روhttp://127.0.0.1:8000/ مراجعه نمایید تا سیستم را تست کنید.

معماری فنی (Technical Stack):
بخش	تکنولوژی/ابزار/توضیحات
بک‌اند (Backend)	Django (5.2.7)	فریم‌ورک اصلی برای مدیریت منطق سمت سرور و پایگاه داده.
پایگاه داده (Database)	SQLite3	پایگاه داده محلی برای ذخیره دائمی اطلاعات وظایف.
رابط کاربری (Frontend)	HTML, CSS (اختیاری)	ساختار صفحه نمایش داده‌ها.
ساختار برنامه	MVT (Model-View-Template)	
الگوی معماری مورد استفاده در Django.

 چگونگی توسعه و بهبود پروژه (Future Enhancements):
این پروژه یک نقطه شروع عالی است. برای ارتقاء این سیستم به سطح حرفه‌ای‌تر، می‌توان موارد زیر را اضافه کرد:

اعتبارسنجی فرم پیشرفته: پیاده‌سازی ModelForms برای اطمینان از ورودی‌های صحیح کاربر در هنگام ثبت وظایف.
مدیریت وضعیت (Status Management): افزودن فیلد وضعیت (مثلاً To Do, In Progress, Completed) و ایجاد یک View مجزا برای تغییر وضعیت‌ها.
احراز هویت (Authentication): پیاده‌سازی سیستم ورود و ثبت نام برای اینکه هر کاربر فقط بتواند وظایف خود را مدیریت کند (استفاده از django.contrib.auth).
جستجو و فیلتر: اضافه کردن قابلیت جستجو بر اساس عنوان یا فیلتر کردن لیست بر اساس وضعیت یا تاریخ ایجاد.
